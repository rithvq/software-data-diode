# N10: Reproducible Baselines and Ablations

Date: 2026-10-15, Asia/Calcutta. Phase N10 only; N11 has not started.
Research description: proposed RCCD mechanism, not established novelty/patentability.

## Scope and Acceptance

N9's 639-test report contained no unresolved tested in-scope correctness failure.
N10 adds an experimentation framework and a disposable deployment override. It
does not change production telemetry, security, persistence, dashboard, credentials,
signing keys or baseline Compose configuration. Existing application/network limits
remain. Source changes were uncommitted on base revision `671cbac`; manifests retain
the exact source fingerprints rather than treating that revision as the new code.

| Requirement | Implementation / evidence |
|---|---|
| Reproducible configuration and seeds | `experiments/workloads/coverage_workloads.json`, original traces, fault fields and source manifests |
| Strong baselines | FIFO/gap barriers, legacy analytics, signed heartbeat, compact exact summaries, matched-RCC-format summaries, RCCD and UNKNOWN control |
| Independent ablations | `no_semantics`, `no_advance`, `no_service`, `no_repeats`, `no_recovery`; unsafe mean assertions stay in the harness |
| Matched total budget | Actual serialized signature/part/control/repeat bytes plus modeled IPv4/UDP overhead; cumulative capacity checks |
| Loads/faults | Light, moderate, near-capacity, overload, burst, critical storm, independent/burst/evidence-only loss, delay/reorder, capacity step and recovery |
| At least five paired trials | 14 cases x 12 arms x 5 seeds = 840 model trials; distinct five-pair actual UDP studies |
| Scoped correctness | Independent full accepted-ingress oracle, original inputs, admission refusals and UNKNOWN explicitly retained |
| Uncertainty | Mean, median, sample SD, observed n and within-seed paired Student-t 95% intervals; no packet pseudoreplication |
| Regenerable figures | Six PNG/PDF figures, aggregate and per-trial raw CSV companions; full signed-artifact replay verified |
| Objective conclusions | Negative findings below; no automatic superiority or patentability claim |

  answers** in these tested accepted-ingress traces.
- 70 intentionally unsafe mean-ablation trials: **two false FALSE answers** and no
  false TRUE answers. They are disclosed, not deployed or counted as successful

- Compact ordinary summaries have higher mean yield in **12 cases**, tie in two
  and are never below RCCD in this matrix. These are case means, not fourteen
  independent hypothesis-test conclusions or an all-settings dominance proof.

cloud resources are added. Cleanup targets only owned test-project state.

## Fixes, Provenance and Limits

- A first heartbeat implementation inherited filtering; that campaign was stopped
  and excluded. Corrected FIFO/heartbeat paths preserve unfiltered original data
  and signed ingress tail barriers. FIFO denotes candidate ordering under the
  common byte-lane server, not one global wire FIFO across traffic classes.
- Recovery-ablation state loss triggered the real N4 `UNSUPPORTED_RECOVERED_FACTS`
  refusal. The harness now records admission unavailability, refuses subsequent
  inputs and produces scoped UNKNOWN rather than bypassing the guard or crashing
  the campaign. All five recovery pairs were rerun.
- Compact-summary development caught binary-magic accounting and outbox-kind
  adapter errors; failed outputs remain excluded. The corrected 70-trial compact
  study uses signed STATE-format parts accounted as logical evidence. It is a
  harness baseline, not a new native Fog persistence schema.
- One live test-container attempt lacked the read-only anomaly configuration
  mount. It was fixed; its failed report is retained, not called a deployment pass.
- The final bundle retains 715 unaffected completed trials, 55 rerun recovery
  trials and 70 compact trials, with exact per-arm source lineage. It does not
  pretend they came from one uninterrupted source version or timing batch. Model
  CPU comparisons are additionally confounded by batch/import/host contention.
- Twenty-second ingress plus four-second deadlines avoids N4's 256 signing-cache
  cap. Its missing phase report and reviewed long-run retirement remain unresolved.
- Five paired seeds per configuration were used; ten would require substantially
  more signing/SQLite/replay time. No packets/windows are independent repetitions.
- Small-link studies use 16 KiB/s (one paired budget uses 32 KiB/s), 50% evidence,
  25% protected and 25% routine. This is not the 10% evidence deployment default,
  which is underfunded at this small link for the frozen contracts. Nominal offered
  load uses a 6,500-byte reference; actual serialized cost is retained.
- Every signature/header/control/part/repeat and 28-byte IPv4/UDP overhead is
  charged. Ethernet/tunnel/NIC overhead is not captured. The capacity step affects
  the serializer; the configured sender estimator remains nominal, with no Fog
  feedback. This is not live dynamic link sensing.
- CPU/RSS/storage describe the model process/common instrumentation; actual
  Docker snapshots are separately reduced to one aggregate per trial. Missing
  critical/incident samples stay null with n shown, not zero. Historical exact raw
  receipt availability does not guarantee post-crash cache retention.
- Student-t intervals are descriptive normal-mean approximations for small,
  bounded/discrete samples and may cross logical bounds. No multiple-comparison
  adjusted superiority inference or pooled incompatible-workload effect is made.
- Trusted gateway assertions remain AUTHENTICATED_SUMMARY. Signatures/input roots
  do not prove hidden measurements. Pre-admission loss, hostile trusted signers,
  physical simultaneity, privileged-host changes and physical one-way enforcement
  are outside this assurance. Measured zero errors is not a universal proof.

## Stop/Go and Next-Phase Prerequisites

Stop any performance-superiority claim for this configuration. Compact summaries
are a stronger cheaper control; the mechanism's richer evidence has not earned a
yield advantage here. Engineering/specification value can continue, but novelty,
inventive step and patentability remain unestablished.

Before any later phase: review the negative findings with faculty; decide whether
to retain a conditional reliability/audit objective or revise the mechanism;
resolve N4 documentation/retirement for long runs; retain compact baselines; use
additional powered incident/critical workloads and genuine online admission
measurements before broad resource/latency claims. No such revision or N11 work
is implemented by this phase.
