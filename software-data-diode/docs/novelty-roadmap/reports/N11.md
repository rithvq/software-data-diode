## Actual Failures Fixed and Retained

The first pilot (`20261015T045409Z-7d8bdb`) failed because the device fixture was
inside the heavyweight coverage package, which imports FastAPI absent from the
intentionally lightweight device image. Moving the device code to `shared/edge`
fixed the packaging without adding dependencies. Docker Desktop also did not
publish the internal-only dashboard mapping; the isolated Fog host bridge fixed
loopback reachability without connecting Fog to Edge.

The next pilot (`20261015T045649Z-891901`) correctly produced positive/negative
decisions but failed its reduction and tampering-deadline assertions: a custom
event name was treated as protected, and snapshot time preceded Fog's grace
deadline. The fixture now uses registered routine event names and an explicit
local-pressure demo policy; snapshot timing respects the actual 20-second grace.
The assertions were not disabled or weakened. Pilot results still say failed.

Before final validation, an inherited shared writable test audit volume was split
per service; the guard refuses cross-zone shared writes. Earlier validation
projects were stopped with state retained, not silently upgraded or counted as
successes. The later fixture also isolates the single environmental-match stage
from the subsequent three-device incident, rather than firing both together.
