## Implementation

Added `shared/coverage/capsules.py` with immutable, separately versioned RCC and contract-transition models. Every scope/identity/meaning field is signed with domain-separated SHA-256/Ed25519 preimages using the existing canonical serializer. It does not wrap evidence in ordinary telemetry or change legacy telemetry signatures or N1 contract hashes.

The original-input commitment has a named, scope-seeded, sequence-ordered hash-fold construction and fixed public vectors. Facts partition each original accepted population into matching/nonmatching/unresolved counts; bounded matching witness references do not disclose hidden values. Counts are derived from canonical original inputs, never a transformed aggregate mean. The complete format, domains, vector and bounds are in [N3-format-v1.md](N3-format-v1.md).

Online authentication yields `AUTHENTICATED_SUMMARY`, under the trusted-gateway assumption. `audit_capsule` separately recomputes disclosed-input counts with independent inequality branches and checks commitment/range/witnesses. It does not call production predicate comparisons or policy methods. Test injection proves a production comparison defect does not alter the independent audit.

The bounded local EvidenceTracker distinguishes exact duplicates, immutable-scope forks and complete/incomplete/broken declared chains. Missing predecessor evidence does not invalidate independently authenticated later-window facts. This inspector is not a durable Fog replay store.

Added `shared/coverage/parts.py`: signed finite-batch transport parts with a hard 1,200-byte serialized datagram limit, logical size/part limits and reorder/duplicate/mix/tamper checks. Whole evidence authentication is required after complete reassembly. There is no socket, UDP listener, continuous assembly daemon, retransmission, ACK or NACK.

## Durable local sealing

Added the explicit `CapsuleSealer` library in `shared/coverage/sealing.py`. It requires an already opened isolated N2 ledger, locally supplied Ed25519 key object and gateway/key IDs. No service imports or automatically instantiates it.

Under the existing serialized writer/SQLite transaction, optional initialization adds schema version/publisher/public-key bindings, a closure-reason column, bounded signed-byte records and per-device chain heads. It stores no private key. Initialization checks prior artifact authentication, row identities, digests, heads and cache capacity; key-ID rebinding and gateway rebinding are refused.

For retained closed observed scopes, it checks durable original counts and recomputed counts against N2's committed fact rows, then atomically commits canonical signed bytes and chain head. Before-commit failure publishes no receipt/bytes; after-commit lost replies return the same retained signed bytes on retry. Actual child-process termination before/after signing commit was exercised. Cached bytes survive restart and raw archival/compaction without resealing; creation time, predecessor and accounting never change on redelivery.

Per-device chain heads enforce increasing window indices; same-scope re-signing is refused. New epochs remain governed by N2's controlled retirement/counter protections, not a random UUID replay reset. Receiver epoch/key approval and durable anti-fork retention remain N6.

The only N2 ledger edits are optional closure-reason recording and an explicit original-column admission insert compatible with the additive column. Stores never opened by the optional sealer retain N2 behavior. Already closed legacy scopes conservatively receive `LEGACY_CLOSURE`/`INTERRUPTED`; exact historical closure reasons are not invented. Tests verify the additive migration does not change existing canonical raw-archive bytes.

## Semantics and unsafe assumptions

Raw disposition, queue-overflow drops, dispatch attempts and confirmed receipt are separate from predicate counts. Overflow is a subset of raw drops; dispositions partition the accepted population. Confirmed receipt is always null/NOT_OBSERVED. A committed predicate fact can represent a later locally dropped raw sample; neither the fact nor its signature proves raw delivery.

No-input, missing-metric, recovery, interruption, clock-discontinuity and transition representations exist. An empty capsule cannot satisfy a contract's required minimum observations. The pure no-input builder is not a runtime liveness certificate; the durable sealer refuses unknown/unobserved windows. No historical empty scopes are synthesized.

Contract transitions are signed local statements, not Fog-to-Edge commands or automatic ledger reconfiguration. Both hashes must already be provisioned. N2's live contract remains pinned.

A signature authenticates the gateway, not unsigned simulated sensors, withheld-input truth or source-generation completeness. A coherent dishonest signed summary can pass online verification; complete disclosed originals can expose the false predicate counts. Offline recomputation still does not prove physical truth, gateway-clock accuracy, durable filesystem anti-rollback or raw transport/drop history.

Bounds are enforced on serialization, counts, lists, original trace records/bytes, signed cache, keys and finite reassembly. The cache fails closed when full; nothing is silently evicted. N2's SQLite page cap still applies, with separate transient-journal/archive headroom. Capsule retention/delivery retirement and live reassembly TTL/concurrency are not implemented in this phase.
